About Networks, systems and community

I'm brick — a Minecraft network owner and content creator. I've been inside the Minecraft ecosystem for years, and I've ended up building both halves of it: the back-end systems, and the community that turns up to use them.

Brickworks Network is mine end to end — development, hosting and content. Alongside it I'm Media Manager and a General Manager at Zyralis Network. I'm confident in Python and Skript, and actively learning Java, JavaScript, HTML and CSS.

Away from Minecraft I run my own infrastructure — Jellyfin and Docker on Ubuntu — which is how I got properly interested in systems, networks and full-stack work in the first place. Breaking my own server and having to fix it taught me more than any tutorial.
